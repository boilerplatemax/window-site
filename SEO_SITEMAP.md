## URL Structure

**Conventions:**
- All lowercase, hyphenated slugs
- Descriptive, keyword-rich paths
- Max 3 levels deep (domain / category / product-type)
- No trailing slashes (canonical)
- Product pages follow: `/[system-type]/[specific-variant]`

## Internal Linking Strategy

### Tier Structure

```
Tier 1 (Most Authority): Home, Category Hubs
    /  →  /windows, /sliding-doors, /folding-glass-walls, /entry-doors

Tier 2 (Product Pages): Each product variant
    Category Hub  →  Product Pages

Tier 3 (Supporting): Projects, Blog, About
    Projects  ↔  Products (bidirectional)
    Blog Posts  →  Product Pages (every post links to 2+ product pages)
    About  →  Contact, Projects
```

### Cross-Linking Rules

1. **Every product page links to:**
   - Its parent category hub
   - 2–3 related products (e.g., floor-to-ceiling → corner glass → sliding doors)
   - 1 relevant project from /projects
   - The /contact page (CTA)

2. **Every blog post links to:**
   - The primary product page it's about
   - 1–2 related product pages
   - 1 relevant project page
   - /contact (soft CTA at end)

3. **Every project page links to:**
   - All products used in that project
   - Related projects (same type or product category)
   - /contact

4. **The homepage links to:**
   - All 4 category hubs
   - 1 featured project
   - /about and /contact

## SEO Technical Notes

### Meta Strategy
- Each page has unique `<title>` following: `[Product Name] | FORMA Architectural Glass`
- Meta descriptions are benefit-led, 150–160 characters
- H1 matches primary keyword intent, H2s target secondary keywords

### Schema Markup Targets
- `Organization` schema on /about and /
- `Product` schema on all product pages
- `BreadcrumbList` on all pages depth ≥ 2
- `FAQPage` schema on product pages with FAQ sections
- `Article` schema on /blog posts
- `LocalBusiness` if a physical location exists

### Image SEO
- All project/product images use descriptive alt text: `"floor to ceiling windows modern living room Vancouver"`
- WebP format, responsive `srcset` for performance
- Filename convention: `lift-slide-door-residential-project.webp`

### Core Web Vitals Targets
- LCP < 2.5s (lazy-load off-screen images, preload hero)
- CLS < 0.1 (reserve space for all images)
- FID/INP < 200ms (minimal JS, Next.js static generation)

### Robots & Indexing
- All product, project, about, contact pages: `index, follow`
- Tag/filter URLs on /projects: `noindex, follow` (avoid duplicate content)
- Sitemap.xml auto-generated via next-sitemap
